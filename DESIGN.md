# Natfio Gallery

Direction: an illustrator's editorial sketchbook. Warm paper (#f7f5ed), ink (#25271f), lemon yellow (#f5ff4f), and a subdued yellow-green paper treatment (#eef19a). Existing illustrations carry the identity; no generated assets or invented project claims.

Instrument Serif provides expressive, large display type and italic punctuation. DM Sans provides readable body copy. The hero uses a two-line wordmark and an arched drawing surface. The profile pairs left-aligned prose with a tilted photographic print. Gallery categories are numbered collection covers, staggered to create a reading rhythm. Artwork pages retain their image-first structure and delayed side reveals. Contact uses a large conversational heading.

Separate routes: About is the entry page, Project starts with category selection, and Contact stands alone. Styling uses Material UI sx and theme configuration only. Mobile layouts stack and preserve image spacing. Motion serves page entry and scroll discovery, plays once per route visit, and uses opacity-only fades for reduced motion.

Existing Canva portrait and artwork exports are low-resolution. Contact address and email remain visibly marked as template details until replaced.
